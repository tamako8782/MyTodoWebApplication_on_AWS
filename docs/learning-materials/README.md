# MyTodoWebApplication_on_AWS 学習教材

## 🎯 この教材について

この教材は、**アイビー・リーメソッド**に基づいた革新的なTodoアプリケーションを通じて、フルスタック開発を学ぶためのものです。

### 🌟 学習目標
- **フルスタック開発の全体像**を理解する
- **実務に近い開発環境**での経験を積む
- **各技術の役割と連携**を体感する
- **モダンなアーキテクチャ**の設計思想を学ぶ

## 📚 学習コンテンツ

### 01. アーキテクチャ編
**学習内容**: システム全体の設計思想と技術選定
- なぜこのアーキテクチャを選んだのか
- 各コンポーネントの役割と責任
- スケーラビリティとメンテナンス性の考慮

### 02. フロントエンド編  
**学習内容**: React + Nginx による SPA 開発
- ユーザーインターフェースの設計
- 状態管理とコンポーネント設計
- APIとの通信とエラーハンドリング

### 03. バックエンド編
**学習内容**: Go による REST API 開発
- RESTful API の設計原則
- データベース接続とCRUD操作
- エラーハンドリングとログ管理

### 04. データベース編
**学習内容**: MySQL によるデータ設計
- テーブル設計とリレーション
- マイグレーション管理
- パフォーマンス最適化

### 05. インフラ編
**学習内容**: AWS + Terraform による IaC
- クラウドインフラの設計
- Infrastructure as Code の実践
- セキュリティとコスト最適化

### 06. デプロイメント編
**学習内容**: Kubernetes + Docker による運用
- コンテナオーケストレーション
- CI/CD パイプライン
- 監視とログ管理

## 🚀 学習の進め方

### 📖 推奨学習順序
1. **アーキテクチャ編** - 全体像の把握
2. **データベース編** - データ設計の理解
3. **バックエンド編** - API開発の実践
4. **フロントエンド編** - UI/UX の実装
5. **インフラ編** - クラウド環境の構築
6. **デプロイメント編** - 運用環境への展開

### 💡 学習のコツ
- **手を動かしながら学ぶ**: コードを実際に書いて動かす
- **なぜそうするのかを考える**: 技術選定の背景を理解する
- **エラーを恐れない**: 失敗から学ぶことが最も重要
- **全体像を意識する**: 各技術がどう連携するかを把握する
