# MyTodoWebApplication_on_AWS 学習教材

## 🎯 この教材について

この教材は、**アイビー・リーメソッドに基づく革新的なTodoアプリ**をフルスタック開発する過程で学べる実践的な学習リソースです。単なるチュートリアルではなく、**なぜそうするのか**、**どのような価値を生み出すのか**を重視した教育的なアプローチを採用しています。

初学者が「この概念なんなの？」「なぜこの実装をしているの？」とつまづきやすいポイントをケアする**参考資料**として活用してください。

## 🛠️ 技術スタック

| 領域 | 技術 | バージョン | 選定理由 |
|------|------|-----------|----------|
| **フロントエンド** | React | 18.3.1 | モダンなUI開発、豊富なエコシステム |
| **バックエンド** | Go | 1.23 | 高性能、シンプルな構文、並行処理 |
| **データベース** | MySQL | 8.0.2 | 信頼性、パフォーマンス、運用実績 |
| **インフラ** | AWS EKS | - | マネージドKubernetes、スケーラビリティ |
| **IaC** | Terraform | - | 宣言的インフラ管理、マルチクラウド対応 |
| **コンテナ** | Docker | - | 環境の一貫性、デプロイの簡素化 |
| **オーケストレーション** | Kubernetes | - | コンテナ管理、自動スケーリング |

# 各技術のインストール（詳細は各章で説明）
