# MyTodoWebApplication_on_AWS ドキュメント

このディレクトリには、プロジェクトに関する2種類のドキュメントが含まれています。

## �� ディレクトリ構造

### 🔧 `refactoring-*/` - リファクタリング記録
プロジェクトの改善・リファクタリングの履歴を記録するディレクトリです。

```
docs/
├── refactoring-001-gitignore-cleanup/  # gitignoreリファクタリング
│   ├── 01-current-state.md            # 現状分析
│   ├── 02-refactor-plan.md            # 改善計画
│   └── 03-result.md                   # 結果報告
├── refactoring-002-xxx/               # 次のリファクタリング
└── ...
```

**対象読者**: 開発者、保守担当者
**目的**: 技術的改善の履歴管理、意思決定の記録

### 📚 `learning-materials/` - Udemy講座教材
アプリケーション初学者向けの学習教材を格納するディレクトリです。

```
docs/learning-materials/
├── 01-architecture/                   # アーキテクチャ解説
├── 02-frontend/                       # フロントエンド解説
├── 03-backend/                        # バックエンド解説
├── 04-database/                       # データベース解説
├── 05-infrastructure/                 # インフラ解説
├── 06-deployment/                     # デプロイメント解説
└── exercises/                         # 演習問題
```

**対象読者**: プログラミング初学者、フルスタック学習者
**目的**: 教育、技術習得支援

## 🎯 使い分けの指針

| 項目 | リファクタリング記録 (`refactoring-*/`) | 学習教材 (`learning-materials/`) |
|------|----------------------------------------|----------------------------------|
| **目的** | 改善履歴の管理 | 教育・学習支援 |
| **読者** | 開発者・保守担当者 | 初学者・学習者 |
| **内容** | 技術的改善の詳細 | 基礎概念・実装意図の解説 |
| **更新頻度** | リファクタリング時 | 機能追加・改善時 |
| **文体** | 技術的・簡潔 | 教育的・丁寧 |

## 📝 ドキュメント作成ガイドライン

### リファクタリング記録の場合
1. **現状分析** → **改善計画** → **結果報告** の3段階構成
2. 定量的な改善効果を明記
3. 技術的な意思決定の根拠を記録

### 学習教材の場合
1. **なぜそうするのか**（要件・背景）
2. **どうやって実装するのか**（実装方法）
3. **何を期待しているのか**（期待効果）
4. **初学者が躓きやすいポイント**（注意事項）
